# BTC Multi-position V1：双仓同向并发

预注册时间：2026-07-17，在运行本路线历史收益之前。

## 目的与边界

用户明确要求解除单持仓限制。诊断显示冻结V5在2024–2025产生202个原始信号，但43个因已有仓位
被忽略，其中40个与持仓同方向。本路线验证：不修改V5信号、止损、目标和市场入场规则，只把最大
并发仓位从1提高到2，能否把被占用的完整V5信号转化为有效交易。

- Route ID：`ict-btc-v5-max2-same-side-v1-2026-07-17`。
- 冻结基线：`ict-btc-v5-2026-07-15`；Route B现有单仓Paper在本轮结果确认前不改。
- 市场：Binance Vision USD-M `BTCUSDT` perpetual `5m`。
- 区间：2021–2023已查看形成诊断、2024和2025已查看评价、2026-01-01至07-13历史复算；
  2026-07-15之后数据不用，所有区间都不是干净留出。
- 自动订单关闭，不接Binance交易API、API key或真实资金。

## 固定并发规则

1. V5的15分钟方向、流动性扫荡、位移、MSS、FVG、波动率比1.25、北京时间18:00至次日08:00
   新入场窗口、结构止损、最大4.25 ATR和2.5R目标全部不变。
2. 每个完整V5信号仍在下一根5分钟开盘按市价成交，不为第二仓另设回撤比例或确认参数。
3. 同时最多2个仓位；已有仓位和待成交信号占用容量。容量已满时不生成第三个待成交订单。
4. 只允许同方向并发。出现与任何现有仓位或待成交订单相反的信号时不建立对冲仓；不启用Binance Hedge Mode。
5. 每仓研究风险为权益0.25%，最大同时初始风险0.50%。仓位按入场时已实现账户权益独立定仓；
   不因已有仓位浮盈扩大新仓风险预算。
6. 每个仓位独立执行自身结构止损和2.5R目标；一个仓位退出不改变另一个仓位的止损或目标。
7. 双边Taker手续费0.045%，每边1 bps不利滑点；每个仓位同K线止损/目标冲突均按止损。
8. 组合权益曲线在每根5分钟K线按所有未平仓仓位收盘价、退出侧不利滑点和预计Taker退出费标记；
   最大回撤同时包含已实现和未实现盈亏。

引擎新增能力必须默认`maxConcurrentPositions=1`，因此所有未显式启用并发的旧策略和Paper保持原行为。
本路线只运行`max=2 / same_side`一套配置，不搜索3仓、4仓或反向对冲。

## 判定门槛

- 2024–2025至少191笔，2024和2025各较单仓增加至少10笔。
- 2024–2025 PF不得低于1.427、平均R不得低于0.271R、净收益必须高于冻结V5；最大逐K线
  标记回撤不超过3.11%，即冻结已实现回撤2.36%上浮最多0.75个百分点。
- 2024、2025和2026历史复算的净收益均为正；多仓版2021–2023不得比同口径单仓PF再低0.05以上。
- 多头和空头在2024–2025合计均不得净亏损。
- 双倍手续费和滑点后，2024–2025 PF仍至少1.00。
- 必须报告最大实际并发数、重叠交易数、逐K线标记回撤、费用、年度、多空和退出结构。

全部通过也只形成独立双仓候选，需要新的前向Paper报告和观察门槛；不得覆盖当前单仓Route B历史报告。
任一失败则保持现有Paper不变，不通过增加到3仓补救。
