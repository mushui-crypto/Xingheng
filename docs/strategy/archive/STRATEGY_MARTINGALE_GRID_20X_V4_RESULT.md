# 固定价差马丁网格 V4：20x 参数研究结果

结论：**路线否决，不修改现网V3自动Paper。**

## 选择结果

18个预注册组合中，仅以下组合通过2024训练门槛：

- 20x隔离；
- 累计保证金上限2.5%，最大名义敞口50%；
- 单组最大计划风险1.5%；
- BTC固定400点、ETH固定20点；
- 12层，层级名义价值倍率1.08；
- 加权均价外4格止盈；
- 第12层之外2格止损；
- 最长持仓24小时。

## 研究解释

20x把相同保证金对应的最大名义敞口从V3的25%提高到50%，但杠杆只会放大已有优势或劣势，不会提高PF。扩大网格和止盈可以在2024改善成本效率，却在2025产生更多超时和尾部亏损，暴露出当前“4h/1h突破确认后逆向建立回撤网格”的状态依赖。

下一步不能继续围绕同一历史反复搜索固定点差、止盈和层倍率。若继续研究，应建立新的预注册路线，优先改变：

1. 将固定绝对点差改为价格比例或已实现波动率分层，避免BTC/ETH价格变化造成网格相对尺度漂移；
2. 区分趋势延续与震荡回归状态，趋势强时不得继续逆向加仓；
3. 20x仅作为保证金效率参数，继续由名义敞口和单组风险上限控制实际风险。

在独立路线通过顺序验证和未来Paper前，不替换V3，不产生真实订单。
