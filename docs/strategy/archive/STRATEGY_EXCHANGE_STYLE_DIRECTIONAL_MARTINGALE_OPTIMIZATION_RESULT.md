# 交易所机器人式多空合约马丁：V2/V2B/V3优化结论

状态：优化路线整体否决；不进入自动Paper，不接前端，不修改生产V3

## 优化范围

本轮没有通过提高杠杆、加大保证金、删除止损或事后删除方向制造收益。固定20x隔离，并将累计保证金从V1的2.5%降至1.5%、单周期计划风险从1.5%降至0.5%。加入0.5%维持保证金率的近似强平压力。

依次验证：

1. V2：4小时冷却或新确认重启、6/8层、0.8%/1.2%止盈、固定/1h ATR间距，共16组。
2. V2B：只把2024达到ETH PF 1.15的两组配置送入2025顺序验证；BTC因16组PF全部低于1直接停止参数搜索。
3. V3：确认后不追突破，等待0.5或1个ATR网格步长回撤，再于下一根5分钟启动，共4组。

## 最终判断

- 网格参数可以降低亏损和回撤，但没有产生跨年份稳定正期望。
- BTC在所有V2组合中PF均低于1，当前4h结构+1h突破不能作为BTC马丁启动因子。
- ETH的2024正收益未能延续到2025和2026，不能单独发布。
- 20x近似强平压力在部分8层ATR配置中实际触发，证明忽略强平会高估深层网格安全性。
- 继续搜索层数、TP、ATR倍率或回撤比例将直接增加同一历史上的过拟合风险。

本轮优化停止。若继续寻找正向策略，应更换策略族，例如顺势回撤的单次风险交易、趋势突破后固定止损，或不使用亏损加仓的多市场因子策略；不再把马丁网格当作当前正收益候选。
