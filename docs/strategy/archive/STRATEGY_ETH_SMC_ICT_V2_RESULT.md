- 2% 档净亏损从 2,447.42 降至 1,894.37 USDT。

分批止盈和 TP1 后保本确实改善了结果，但 PF 仍约为 `0.40`，平均 R 仍显著为负，不能把“改善”误写成“有效”。

## 杠杆与风险解释

- `100x` 是交易所仓位杠杆设置；
- 初始保证金使用权益的 `2% / 3% / 4% / 5%`，对应约 `2x / 3x / 4x / 5x` 的初始账户名义敞口；
- 这不等于把整个账户以 100x 建仓；
- 全仓模式下，账户其余可用权益可能参与维持仓位，风险不能仅用“单笔保证金百分比”描述；
- 5% 档连续回撤达到 V2A 58.46%、V2B 46.60%，不应使用更高保证金掩盖负期望。

## 已知限制

- 未计资金费率；
- 维持保证金率暂按 `0.50%` 研究假设，不是账户实际 Binance leverage bracket；
- 数量仍按连续 ETH 计算，未执行 `0.001 ETH` 步长取整；
- 价格 tick `0.01` 和最小名义价值 `20 USDT` 尚未进入执行适配；
- 5m OHLC 无法恢复 K 线内路径，因此采用“清算 → 止损 → TP1 → 移动后 BE → TP2”的保守顺序；
- TP1 已实现收益只在整笔仓位最终关闭后进入 equity curve，退出腿 PnL 和费用仍逐腿记录；
- 全仓清算假设账户没有其他仓位和挂单共同消耗抵押物。

## V3 研究边界

V3 必须在首次运行前另建规则文档和 route id。建议优先研究：

1. 更严格的高周期方向一致性，而不是仅使用上一根 15m 收盘相对 EMA；
2. 限制 liquidity sweep 到 MSS 的最大等待时间，减少过期扫荡被错误关联；
3. 加入趋势/波动 regime 过滤，隔离 2025–2026 的失效环境；
4. 设置最长持仓或明确的时间止损，避免 17–21 小时暴露偏离 ICT 日内交易假设；
5. 将 short-only 作为独立预注册路线研究，不得从 V2 结果中事后删除多头；
6. 保留结构止损与 `20–40` 点约束，优先从 `2%` 初始保证金验证，不以 5% 放大失败信号。

V3 即使通过历史基线，也必须进入新的、未参与参数选择的 forward paper 阶段，不能直接自动执行。
