# 交易所机器人式震荡区间合约网格 V1

状态：历史复算否决；不进入自动 Paper

## 参考模型

参考 Binance、OKX、Bybit 的合约网格机器人共同机制：预设价格区间与网格数量，区间内持续买低卖高；成交一格后，以相邻一格作为反向平仓目标；机器人持续运行，不设置挂单或持仓到期时间。

## 区间识别

- 只使用已完成4小时K线。
- 摆动高低点均采用左右2根确认。
- 最近两个高点和最近两个低点不能同时构成HH/HL或LH/LL趋势。
- 两个高点之间、两个低点之间的偏差均不得超过候选区间宽度20%。
- 区间宽度必须为中点价格的3%至15%，当前价格必须位于区间内部。
- 上界取最近两个确认高点均值，下界取最近两个确认低点均值。

## 网格与生命周期

- BTCUSDT、ETHUSDT分别独立运行。
- 上下界之间使用12格等差网格。
- 中点以下维护6个多头网格，中点以上维护6个空头网格。
- 每一层使用相同名义价值；成交后在有利方向相邻一格止盈，止盈后该层重新开放。
- 挂单和持仓均无时间限制。
- 区间下方或上方1格为整组结构终止边界；触发时按保守路径关闭全部未完成网格，等待新的已确认区间。
- 同K线先成交所有不利触及层，再判断区间止损；新成交层不得在同一K线按有利目标退出。

## 资金与风险

- 每品种初始Paper权益5,000 USDT。
- 20x隔离风险模型。
- 12层全部占用时，累计保证金不超过权益2.5%，名义敞口不超过权益50%。
- 若区间边界风险超过权益1.5%，所有层按同比例缩小。
- Taker费0.045%、单边不利滑点1bp；另做双倍成本压力测试。
- 资金费、Mark Price动态强平、盘口冲击和交易所数量取整暂时忽略。
- Paper only，不接API Key，不产生真实订单。

首次运行不调参数，报告2024、2025、2026-01-01至07-15以及全区间的完成网格、区间周期、净收益、PF、费用与逐K线回撤。历史已被观察，不是干净留出；只有跨年度一致且双倍成本仍有安全边际，才允许进入独立自动Paper。
